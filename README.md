🌦️ Weather App

A responsive weather application built using HTML, CSS, and JavaScript that allows users to search for real-time weather information for any city worldwide.

This project demonstrates API integration, DOM manipulation, asynchronous JavaScript, and responsive UI design.

🚀 Features

🔍 Search weather by city name

🌡️ Displays temperature, weather condition, humidity, and wind speed

🕒 Real-time data from weather API

📱 Fully responsive design

⚡ Fast and lightweight (Vanilla JavaScript – no frameworks)

🛠️ Built With

HTML5 – Structure

CSS3 – Styling & responsive design

JavaScript (ES6) – Logic & API integration

Weather API – For real-time data (e.g., OpenWeatherMap)

📂 Project Structure
weather-app/
│
├── index.html      # Main HTML file
├── style.css       # Styling
├── script.js       # JavaScript logic
└── README.md       # Project documentation
⚙️ How It Works

User enters a city name.

JavaScript fetches weather data from the API using fetch().

The response is converted to JSON.

Weather details are dynamically displayed on the page.

Errors (e.g., invalid city) are handled gracefully.

🔑 API Setup

If you're using OpenWeatherMap:

Create a free account.

Generate an API key.

Replace the placeholder in script.js:

const apiKey = "YOUR_API_KEY_HERE";
▶️ How to Run Locally

Clone the repository:

git clone https://github.com/yourusername/weather-app.git

Open the project folder.

Open index.html in your browser.

No server setup required.
